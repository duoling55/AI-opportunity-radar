# 自动信源发现 - 重要性评分设计

> 所属：FR-15 自动信源发现（P0 新增）
> 关联 spec：[[01 搜索任务执行]] · [[02 门户直接抓取]] · [[03 自动合规核查]] · [[05 06页面与信源交互]]

## 1. 目的与范围

本 spec 是 FR-15 的**叶子能力模块**：对发现信源自动计算重要性与优先级评分（6 维度，满分 100），输出总分、优先级分级与评分要素，供用户手动判断哪些信源值得加入启用。

**纳入**：6 维度评分计算、分级、评分要素说明生成。

**不纳入**：搜索编排（Spec 1）、门户直接抓取（Spec 2）、合规核查（Spec 3）、前端展示（Spec 5）。本 spec 只产出 `ScoreResult`。

**定位**：评分是**辅助决策**，不自动启用任何信源。启用决策权在人工（Spec 5）。

## 2. 功能描述

系统对发现信源自动判断重要性与优先级，按行政层级、行业相关性、融资信号密度、政策更新频率、合规可采集性、域名权威性 6 维度评分，展示总分、优先级与评分要素（如"国家级信源 +30""金融租赁直接相关 +25"），用户据此手动判断。

## 3. 用户故事

- 作为运营，我希望看到每个候选信源的重要性评分和评分要素（如国家>地方、租赁>其他金融），以便手动判断哪些值得加入。

## 4. 输入输出

- **输入**：发现信源（`discovery.admin_level`、`domain`、`sample_policies`、栏目名）+ Spec 3 的 `ComplianceReport`
- **输出**：`ScoreResult`

| 字段 | 类型 | 说明 |
|---|---|---|
| `priority_score` | `int` (0-100) | 总分 |
| `priority_level` | `Literal["高","中","低"]` | 优先级分级 |
| `score_breakdown` | `list[{dimension, score, max, reason}]` | 各维度得分与要素说明 |

## 5. 评分规则（D9，满分 100）

| 维度 | 分值 | 判断标准 |
|---|---|---|
| 行政层级 | 30 | 国家级 30 / 省级 20 / 市级及以下 10 |
| 行业相关性 | 25 | 金融租赁直接相关 25 / 其他金融 15 / 产业通用 10 / 非金融 5 |
| 融资信号密度 | 20 | 样例政策含融资信号比例：高 20 / 中 10 / 低 5 |
| 政策更新频率 | 10 | 高频（周更）10 / 中频（月更）5 / 低频 2 |
| 合规可采集性 | 10 | 公开可采集 10 / 需关注 5 / 受限 0 |
| 域名权威性 | 5 | gov.cn 官方 5 / 其他 0 |

**分级**：高（≥80）/ 中（60-79）/ 低（<60）。

## 6. 数据模型与接口

```python
class ImportanceScorer:
    def score(self, source: CandidateSource, samples: list[SamplePolicy],
              compliance_report: ComplianceReport) -> ScoreResult: ...
```

### 6.1 各维度信号判定

| 维度 | 信号来源 | 判定 |
|---|---|---|
| 行政层级 | `discovery.admin_level`（取自门户种子） | 国家->30 / 省->20 / 市及以下->10 |
| 行业相关性 | 样例政策文本 + 栏目名 | 命中融资租赁关键词（设备租赁/融资租赁/绿色租赁/售后回租/设备直租等）->25；其他金融关键词（贴息/担保/信贷/融资支持等）->15；产业通用关键词->10；均未命中->5 |
| 融资信号密度 | 样例政策命中融资信号比例 | ≥60%->20（高）/ 30-59%->10（中）/ <30%->5（低） |
| 政策更新频率 | 样例政策日期跨度（DOM/文本提取的发布日期） | 周更->10 / 月更->5 / 低频->2；样例不足时取中频 5 并在 reason 标注"样例不足" |
| 合规可采集性 | Spec 3 `check_result` | pass->10 / needs_attention->5 / not_recommended->0 |
| 域名权威性 | `domain` | `*.gov.cn`->5 / 其他->0 |

### 6.2 评分要素说明

每维度的 `reason` 给出可读说明，例如：
- `"国家级信源 +30"`
- `"金融租赁直接相关 +25"`
- `"样例融资信号密度 72%（高）+20"`
- `"robots 允许、公开可采集 +10"`

要素说明供 Spec 5 在候选确认页直接展示。

## 7. 与现有实现差异

现有项目无信源重要性评分。本 spec 新增 6 维度评分、分级与要素说明。评分规则与 PRD FR-15"D9 自动信源发现"决策一致，分值与维度完全对齐。

## 8. 验收标准

1. 按 6 维度评分，分值与 §5 表一致，总分等于各维度之和且 ≤100。
2. 输出 `priority_score`、`priority_level`（高/中/低）、`score_breakdown`（含每维度得分与要素说明）。
3. 合规可采集性维度取自 Spec 3 `check_result`；行政层级取自门户种子。
4. 样例不足时降级取中频分值并在 `reason` 标注，不报错中断。
5. 评分为辅助决策，不自动启用任何信源；`ScoreResult` 供 Spec 5 展示。
6. `ImportanceScorer` 可注入 mock 数据单测，验证各维度判定与总分计算。

## 9. 依赖与关联

- **依赖**：Spec 3（`ComplianceReport`，作为合规可采集性维度输入）。
- **被依赖**：Spec 1（`ImportanceScorer.score`）。
- **关联**：FR-15 重要性评分规则（D9）。
